# GRE Vocab Study Web App

**Goal:** A mobile-friendly React SPA deployed to GitHub Pages (`plusparth.github.io/gre-vocab-app`) for studying GRE vocabulary through flashcards, mix-and-match, and fill-in-the-blank modes, with SM-2 spaced repetition progress tracking.

---

## Stack

- **Frontend:** React + TypeScript + Vite
- **State management:** Zustand (word selection, SM-2 progress, session state)
- **Routing:** React Router (client-side, hash-based for GitHub Pages)
- **Persistence:** localStorage (SM-2 progress keyed by word)
- **Deployment:** `gh-pages` npm package → `gh-pages` branch → GitHub Pages
- **Data:** Static `web/src/data/words.json` bundled at build time — no runtime API calls

## Data Layer

### `words.json` shape (per entry)

```json
{
  "word": "abase",
  "prefix": "ab",
  "pos": "verb",
  "definition": "to lower in rank, office, prestige, or esteem",
  "mwSentence": "… the shame that had abased him within and without …",
  "etymology": "Latin ad- + bassus 'low'",
  "notes": "",
  "sentenceSets": [
    {
      "sentence": "After the scandal, the once-celebrated general was abased to a minor administrative post.",
      "answerChoices": [
        { "distractor": "demote",    "closeness": 3, "reasoning": "Close but incorrect — 'demote' refers specifically to job rank, while 'abase' implies a broader lowering of dignity and self-worth." },
        { "distractor": "humiliate", "closeness": 3, "reasoning": "Close — shares the sense of dignity loss, but 'humiliate' describes a momentary act; 'abase' implies a lasting reduction in status." },
        { "distractor": "censure",   "closeness": 2, "reasoning": "Moderate — censure involves formal criticism and can accompany abasement, but does not carry the same meaning." },
        { "distractor": "extol",     "closeness": 1, "reasoning": "Incorrect — 'extol' means to praise highly, the opposite direction entirely." }
      ]
    },
    {
      "sentence": "She refused to abase herself by apologizing for something she had not done.",
      "answerChoices": [ "..." ]
    },
    {
      "sentence": "The emperor's edicts were designed to abase the conquered people and crush any sense of pride.",
      "answerChoices": [ "..." ]
    }
  ]
}
```

**Target sentences per word:** 3. The first is the existing Claude-generated sentence (`cache/sentences/`); two additional sentences are generated alongside their answer choices.

**Sentence diversity requirement:** The 3 sentences for a word must use meaningfully different contexts — different subject domains, different syntactic roles, different connotations of the word. The goal is that a distractor that is a strong trap in one sentence's context (e.g., "demote" for a workplace sentence about "abase") should be a weaker or implausible distractor in another sentence's context (e.g., a sentence about self-abasement in a religious setting). This ensures distractors are generated per-sentence rather than reused across sentences, and that the full set of 3 sentences tests the word's meaning broadly rather than from one angle.

**Closeness scale:**
- `3` — near-synonym or easily confused (trap answer)
- `2` — plausible in context but wrong
- `1` — clearly wrong or antonym

**Target distribution per sentence:** 4 closeness-3 + 4 closeness-2 + 3 closeness-1 = 11 distractors.

**Multiple choice presentation:** app picks 1 correct + 2 closeness-3 + 1 closeness-2 + 1 closeness-1 = 5 options (GRE style). The app randomly selects which sentence set to use **per question** (not per session), then randomly draws from that set's distractor tiers — giving ~990 unique combinations per word across 3 sentences.

**Important:** `sentenceSets[*].sentence` is used **only** in fill-in-blank modes. Flashcard backs show `mwSentence` only.

### `scripts/build_data.py`

Merges `cache/{word}.json` + `cache/sentence_sets/{word}.json` + `output/populated.csv` into `web/src/data/words.json`. Run after any cache update; output is committed.

## Sentence & Answer Choice Generation

### Prompt file: `prompts/answer_choices.md`

The canonical prompt used in Claude Code sessions to generate `cache/sentence_sets/{word}.json`. Contains:
- Instructions to generate 3 sentences per word (incorporating the existing sentence from `cache/sentences/` as the first)
- Sentence diversity requirement: each sentence must use a different domain/context/syntactic role so that strong distractors for one sentence are not strong distractors for the others
- Closeness scale definition (1–3)
- Target distribution per sentence (4/4/3 = 11 distractors)
- Output JSON schema
- GRE style guidance (near-synonyms as traps, plausible-in-context midrange, opposites as easy eliminations)
- Worked example input/output showing 3 diverse sentences with context-specific distractor sets

Generation is a one-time Claude Code session task, not a runtime API call. Already-cached words are skipped on re-run.

```json

  "word": "abase",
  "sentenceSets": [
    {
      "sentence": "After the scandal, the once-celebrated general was abased to a minor administrative post.",

        { "distractor": "humiliate", "closeness": 3, "reasoning": "..." },
        { "distractor": "degrade",   "closeness": 3, "reasoning": "..." },
        { "distractor": "disparage", "closeness": 3, "reasoning": "..." },
        { "distractor": "censure",   "closeness": 2, "reasoning": "..." },
        { "distractor": "condemn",   "closeness": 2, "reasoning": "..." },
        { "distractor": "rebuke",    "closeness": 2, "reasoning": "..." },
        { "distractor": "chastise",  "closeness": 2, "reasoning": "..." },
        { "distractor": "extol",     "closeness": 1, "reasoning": "..." },
        { "distractor": "exalt",     "closeness": 1, "reasoning": "..." },
```

`build_data.py` reads this file and embeds the full `sentenceSets` array into `words.json`. The old `cache/sentences/` files are used as the seed for sentence index 0 during generation and are otherwise superseded.

## Navigation & Layout

**Persistent sidebar** — always visible in word bank view, collapses to a 44px icon rail in all quiz modes (Flashcards, Match, Fill in Blank).

**Sidebar items:** Word Bank · Flashcards · Match · Fill in Blank · Progress · [Start Quiz button]

**Mode switching:** clicking any icon rail item in quiz mode switches mode but preserves the current word selection. Word Bank icon restores expanded sidebar.

**Start Quiz:** launches the last-active quiz mode with the current word selection.

## Word Bank (Word Selection)

Filters (combinable):
- **Search:** free-text search over word + definition
- **Prefix/root/suffix:** filter chips by morpheme
- **Mastery status:** New / Due for review / Mastered / Struggling
- **SM-2 due date:** show only words due ≤ today

Sort options: A–Z · Z–A · Random

**First-N selector:** "First N of M" — select the top N words from the current filtered+sorted list.

Each word row shows: checkbox · word · POS · SM-2 status (new / streak checkmarks / due date).

Multi-select with drag-to-select supported.

## Study Modes

### Flashcards

- **Front:** word, part of speech, prefix/root/suffix
- **Back:** definition · M-W example sentence (word bolded) · etymology
- **Reverse mode toggle:** show definition first, tap to reveal word
- **SM-2 rating buttons on back:** Missed (0) · Hard (2) · Good (4) · Easy (5)
- Cards advance automatically after rating; SM-2 interval updates immediately

### Mix-and-Match

- 6 word-definition pairs displayed at a time (words left column, definitions right column)
- Click a word to select it, click a definition to attempt the match
- Correct: both tiles lock green and cross out
- Incorrect: both tiles flash red and deselect
- Progress bar shows matched pairs across all rounds
- SM-2 update: correct match → quality 4; incorrect → quality 1

### Fill in Blank

**Two sub-modes** (toggle at top of page):

**True fill-in-the-blank:**
- Claude-generated sentence shown with the word replaced by a text input field
- User types their answer and submits
- Matching is case-insensitive and also accepts any M-W stem for the word (e.g., "abased", "abasing" accepted for "abase")
- Correct: green highlight, show word + definition
- Incorrect: red highlight, show correct answer + definition

**Multiple choice:**
- Claude-generated sentence with blank
- 5 answer choices: 1 correct + 2 closeness-3 + 1 closeness-2 + 1 closeness-1 (randomly drawn each time)
- GRE-style labeling: (A) through (E)
- After submission: show which was correct, display reasoning for each incorrect option
- SM-2 update: correct → quality 4; incorrect → quality 1

## SM-2 Progress System

### localStorage schema (per word)

```json
{
  "abase": {
    "interval": 4,
    "easeFactor": 2.5,
    "repetitions": 3,
    "dueDate": "2026-06-25",
    "lastMode": "fillInBlank"
  }
}
```

### Quality score mapping

| Action | Quality |
|--------|---------|
| Flashcard: Missed | 0 |
| Flashcard: Hard | 2 |
| Flashcard: Good | 4 |
| Flashcard: Easy | 5 |
| Fill-in-blank / Match: Correct | 4 |
| Fill-in-blank / Match: Incorrect | 1 |

Standard SM-2 algorithm: interval and easeFactor update after each answer.

### Mastery filter definitions

| Filter | Condition |
|--------|-----------|
| New | No SM-2 record |
| Due for review | dueDate ≤ today |
| Mastered | repetitions ≥ 3 and interval ≥ 21 days |
| Struggling | easeFactor < 1.8 |

## Build & Deploy Workflow

1. **Generate sentence sets** — Claude Code session reads `prompts/answer_choices.md`, generates `cache/sentence_sets/{word}.json` for all ~2,752 words (3 sentences + 11 distractors each), seeding sentence 0 from `cache/sentences/`; skips already-cached entries
2. **Build data** — `python scripts/build_data.py` → regenerates `web/src/data/words.json`
3. **Commit** — commit `cache/sentence_sets/`, `web/src/data/words.json`
4. **Deploy** — `cd web && npm run deploy` → builds Vite app, pushes `dist/` to `gh-pages` branch → live at `plusparth.github.io/gre-vocab-app`

Vite config sets `base: '/gre-vocab-app/'` and React Router uses hash-based routing (`HashRouter`) for GitHub Pages compatibility.

## Out of Scope

- User accounts or server-side persistence
- Audio pronunciation
- Multi-blank GRE text completion questions (only single-blank)
- Sharing or exporting progress
- Updating answer choice cache after initial generation
